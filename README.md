# Tempo

버전별 추가 기능·개선 사항·오류 수정은 [변경 이력](CHANGELOG.md)에서 확인할 수 있습니다.

푸시 전에는 버전과 변경 이력을 함께 갱신하고 `npm run release:check`로 확인합니다.

Windows용 로컬 활동 시간 기록 데스크톱 앱. Electron 전용 창으로 실행되며 Chrome 설치가 필요하지 않습니다. 개발 환경은 Node.js 22.12 이상이며 최초 설치는 npm install을 사용합니다.

## 실행

바탕화면 Daylog 아이콘이나 `start.cmd`를 실행하면 Daylog 전용 창이 열립니다. 개발 실행은 `npm start`, 숨김 실행은 `npm run start:quiet`, 서버 단독 실행은 `npm run start:server`입니다.

주소창이나 브라우저 탭 없이 별도 앱 창과 작업표시줄 아이콘으로 표시됩니다. 창의 X 버튼을 누르면 트레이로 숨기고 기록은 계속합니다. 트레이의 Daylog 아이콘을 더블클릭하거나 오른쪽 메뉴에서 화면을 열 수 있습니다. ‘Daylog 종료 (기록 중지)’는 기록을 저장하고 서버와 트레이를 종료합니다. 앱 창을 닫는 것만으로는 기록이 중지되지 않습니다. 서버가 예기치 않게 종료되면 트레이가 재실행합니다.

자동 실행 등록: `powershell.exe -NoProfile -File windows/install-startup.ps1`. 현재 Windows 사용자의 시작프로그램 폴더에 Daylog 바로가기 하나를 등록합니다. 관리자 권한이나 서비스 설치 없이 로그인 때 조용히 시작되며, 트레이의 ‘Windows 로그인 시 자동 실행’을 해제하면 등록이 삭제됩니다. 프로젝트 폴더를 이동하면 자동 실행을 다시 등록해야 합니다. 데스크톱 앱 오류는 `data/desktop.log`에 기록합니다.

## 지원 기능

- 설정 → 시작 설정 → Windows 시작 시 자동 실행 스위치로 켜거나 끌 수 있습니다. 스위치는 Windows 시작프로그램 바로가기를 실제로 등록/해제합니다. 끄더라도 현재 실행과 기록은 유지되며 다음 로그인부터 적용됩니다. 트레이 메뉴와도 동기화됩니다.
- 바탕화면, 트레이, 앱 로고는 차콜 배경의 시계 심벌을 사용합니다.

- 게임/프로그램: 활동 설정에서 실제 프로세스 이름을 지정하면 실행 여부를 2초 간격으로 확인합니다. 게임 분류는 창이 존재할 때만 기록하므로 종료 후 남은 백그라운드 프로세스는 제외합니다. 창 밖으로 이동해도 기록합니다. 최소화 상태도 포함됩니다.
- 수동 활동: 독서, 직접 작업 등의 시작/정지.
- 유튜브: `extension` 폴더를 Chrome/Edge 확장 관리 화면의 개발자 모드에서 로드합니다. 확장 아이콘을 눌러 Daylog 설정 화면에서 복사한 연동 키를 저장한 뒤 유튜브를 새로고침합니다. 재생 중인 여러 탭의 시간은 중복 계산하지 않습니다. 탭 종료나 연결 장애 시 최장 45초 감지 지연이 있을 수 있습니다.
- AI: 이벤트 수신 API와 `integrations/ai-example.js` 래퍼를 제공합니다. Codex는 로컬 세션 JSONL의 task_started/task_complete 이벤트를 자동 감지합니다(실험적). 오늘과 어제의 세션을 발견하고 이후 새 이벤트를 읽습니다. 시작 시 5분 이상 갱신되지 않은 미완료 세션은 재개하지 않습니다. 내부 로그 형식 변경과 승인 대기는 완전히 감지하지 못할 수 있습니다. 다른 AI는 실제 실행 경로에서 래퍼를 연결하고 입력 대기 시 종료 신호를 보내야 합니다.
- 날짜별 대시보드, 달력, 최근 7일 통계, 기록 수정/삭제, 날짜별 CSV 내보내기.

## 시간 규칙

활동 기록은 기본적으로 같은 활동이 5분 이내에 재개되면 한 묶음으로 표시합니다. 게임 종류가 다르거나 긴 휴식이 있으면 따로 표시합니다. 묶음의 시간은 실제 구간의 합집합으로 계산하므로 공백이나 중복 시간이 더해지지 않습니다. 묶음을 펼치면 원본 구간을 확인·수정할 수 있으며 ‘개별 보기’로 모든 원본 기록을 볼 수 있습니다. 이 기능은 표시 방식만 바꾸며 저장된 기록과 CSV 내보내기는 원본을 유지합니다.

코딩 시간에는 AI 실행뿐 아니라 Codex/ChatGPT 데스크톱 창에서 직접 메시지를 작성하거나 조작하는 시간도 포함합니다. 활성 프로세스 이름과 마지막 입력 이후 경과 시간만 확인하며 입력한 글자는 읽거나 저장하지 않습니다. 다른 앱으로 전환하거나 60초간 입력이 없으면 직접 작업 측정은 멈춥니다. AI가 백그라운드에서 실행 중이면 측정은 계속되며 동시에 직접 작업해도 한 번만 계산합니다. Codex/ChatGPT 창 안의 대화 종류는 구분하지 않습니다. ‘독서와 생각 정리’ 기본 카드는 보관 처리되며 지난 기록은 유지됩니다.

게임 활동 하나에 여러 게임을 등록할 수 있습니다. 게임 카드의 설정에서 게임 이름과 실행 프로그램을 입력하고 ‘목록에 추가’를 누른 뒤 저장하세요. 등록한 게임 중 하나라도 창이 열려 있으면 측정하고, 모두 닫히면 멈춥니다. 기록에는 실행된 게임 이름이 남으며 게임 전환 시 구간이 나뉩니다. 여러 게임이 동시에 실행되어도 그룹 시간은 한 번만 계산합니다. 목록에서 게임을 제외해도 지난 기록은 보존합니다. 첫 적용 전에 기존 데이터는 `data/state.before-game-groups.json`으로 백업됩니다.

전체 시간은 겹친 구간을 한 번만 계산합니다. 활동별 비율은 분류별 시간의 합계를 기준으로 하므로 동시 활동이 포함됩니다. 게임은 실행 프로세스와 창의 존재 여부를 측정하며 실제 플레이 여부를 판단하지 않습니다. 자정이 지나면 각 날짜에 나누어 표시합니다. AI/영상 이벤트는 15초 정도 간격의 유지 신호가 필요하며 기본 유효 기간은 45초입니다. 수동 정지는 감지 신호보다 우선하고, 다시 측정을 켜야 재개됩니다.

## 데이터와 범위

기록과 로컬 연동 키는 `data/state.json`에 있습니다. 외부 서버로 기록을 전송하지 않습니다. Google Fonts를 불러오며 네트워크가 없으면 시스템 글꼴로 표시됩니다. 서버는 127.0.0.1에만 바인딩됩니다. PC 절전 중 원격 AI 실행 시간 복구, 일반 앱 입력 감지, 카운트다운, 배포용 설치 파일은 이번 버전에 포함하지 않았습니다. 상태 확인이 끊긴 구간은 기록 수정으로 정리할 수 있습니다.
